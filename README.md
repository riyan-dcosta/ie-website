# ie-website

A responsive, two-page static website for a coco peat merchant export business.

## Preview

Open `index.html` in a browser. The site uses plain HTML, CSS and JavaScript, with no build step or dependencies.

## Before launch

- Replace the sample company identity, CXO names and email addresses in `index.html` and `contact.html`.
- Update the social profile links and replace the sample QR code destination in `contact.html`.
- Confirm product specifications, sourcing details and destination requirements before publishing any commercial claims.

Images and font files are loaded from external services; an internet connection is needed to display them.
